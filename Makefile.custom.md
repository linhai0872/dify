# Makefile.custom 命令速查

用法: make -f Makefile.custom <命令>


## 一、三环境核心操作命令

┌──────────┬──────────────────┬──────────────────┬──────────────────┐
│   操作   │ 开发环境 (dev-)  │ 测试环境 (test-) │ 生产环境 (prod-) │
├──────────┼──────────────────┼──────────────────┼──────────────────┤
│ 初始化   │ dev-setup        │ test-setup       │ prod-setup       │
│ 一键启动 │ dev-start        │ test-start       │ prod-start       │
│ 启动容器 │ dev-up           │ test-up          │ prod-up          │
│ 停止     │ dev-down         │ test-down        │ prod-down        │
│ 重启     │ dev-restart      │ test-restart     │ prod-restart     │
│ 构建镜像 │ —                │ test-build       │ prod-build       │
│ 推送镜像 │ —                │ —                │ prod-push        │
│ 滚动更新 │ —                │ —                │ prod-deploy      │
│ 查看日志 │ dev-logs         │ test-logs        │ prod-logs        │
└──────────┴──────────────────┴──────────────────┴──────────────────┘


## 二、开发环境 (macOS 源码热重载)

┌───────────────────────┬──────────────────────────────────────────┐
│ 命令                  │ 作用 / 场景                              │
├───────────────────────┼──────────────────────────────────────────┤
│ dev-setup             │ 检查依赖 → 初始化 .env → 构建 Sandbox   │
│                       │ 首次拉取项目后执行一次                   │
├───────────────────────┼──────────────────────────────────────────┤
│ dev-start             │ 一键启动全栈 (中间件+后端+Worker+前端)   │
│                       │ 日常开发                                 │
├───────────────────────┼──────────────────────────────────────────┤
│ dev-up                │ 仅启动中间件容器 (DB/Redis/Sandbox 等)   │
│                       │ 只需中间件，后端手动起                   │
├───────────────────────┼──────────────────────────────────────────┤
│ dev-down              │ 停止所有 (杀进程+停中间件)               │
│                       │ 结束开发                                 │
├───────────────────────┼──────────────────────────────────────────┤
│ dev-restart           │ 完全重启全栈                             │
│                       │ 环境异常时重置                           │
├───────────────────────┼──────────────────────────────────────────┤
│ dev-api               │ 前台启动后端 (Flask debug)               │
│                       │ 需要实时看后端输出                       │
├───────────────────────┼──────────────────────────────────────────┤
│ dev-web               │ 前台启动前端 (Next.js dev)               │
│                       │ 单独启动前端                             │
├───────────────────────┼──────────────────────────────────────────┤
│ dev-worker            │ 前台启动 Celery Worker                   │
│                       │ 需要实时看 Worker 输出                   │
├───────────────────────┼──────────────────────────────────────────┤
│ dev-logs              │ 查看后端日志                             │
│ dev-logs-worker       │ 查看 Worker 日志                         │
└───────────────────────┴──────────────────────────────────────────┘


## 三、测试环境 (macOS Docker 全容器)

┌───────────────────────┬──────────────────────────────────────────┐
│ 命令                  │ 作用 / 场景                              │
├───────────────────────┼──────────────────────────────────────────┤
│ test-setup            │ 检查依赖 → 初始化 .env                   │
│                       │ 首次配置，执行一次                       │
├───────────────────────┼──────────────────────────────────────────┤
│ test-start            │ 构建镜像 → 启动容器 → 健康检查           │
│                       │ 验收功能，验证容器化部署                 │
├───────────────────────┼──────────────────────────────────────────┤
│ test-build            │ 构建 API(含 LibreOffice)+Web 镜像        │
│                       │ 源码改动后重新构建                       │
├───────────────────────┼──────────────────────────────────────────┤
│ test-up               │ 合并环境变量 → 启动容器 (不构建)         │
│                       │ 镜像已存在，快速启动                     │
├───────────────────────┼──────────────────────────────────────────┤
│ test-down             │ 停止测试容器                             │
│                       │ 释放资源                                 │
├───────────────────────┼──────────────────────────────────────────┤
│ test-restart          │ 重启容器 (不重新构建)                    │
│                       │ 只改了配置                               │
├───────────────────────┼──────────────────────────────────────────┤
│ test-logs             │ 查看容器日志                             │
│                       │ 排查问题                                 │
└───────────────────────┴──────────────────────────────────────────┘


## 四、生产环境 (Linux Docker 部署)

┌───────────────────────┬──────────────────────────────────────────┐
│ 命令                  │ 作用 / 场景                              │
├───────────────────────┼──────────────────────────────────────────┤
│ prod-setup            │ 检查依赖 → 初始化 .env                   │
│                       │ 服务器首次部署，执行一次                 │
├───────────────────────┼──────────────────────────────────────────┤
│ prod-start            │ 构建 → 推送 → 滚动更新 (全流程)         │
│                       │ 首次部署或全量更新                       │
├───────────────────────┼──────────────────────────────────────────┤
│ prod-build            │ 构建 API(含 LibreOffice)+Web 镜像        │
│                       │ 本地/CI 构建生产镜像                     │
├───────────────────────┼──────────────────────────────────────────┤
│ prod-push             │ 推送镜像到 DOCKER_REGISTRY               │
│                       │ 构建后推送到仓库                         │
├───────────────────────┼──────────────────────────────────────────┤
│ prod-deploy           │ 拉取 → 更新 API → 健康检查 → 更新       │
│                       │ Worker → 更新 Web (失败自动回滚)         │
│                       │ 服务器侧零停机更新                       │
├───────────────────────┼──────────────────────────────────────────┤
│ prod-up               │ 合并环境变量 → 启动容器 (不拉取)         │
│                       │ 已有镜像快速启动                         │
├───────────────────────┼──────────────────────────────────────────┤
│ prod-down             │ 停止生产容器                             │
│                       │ 维护停机                                 │
├───────────────────────┼──────────────────────────────────────────┤
│ prod-restart          │ 重启容器 (不拉取新镜像)                  │
│                       │ 只改了配置                               │
├───────────────────────┼──────────────────────────────────────────┤
│ prod-logs             │ 查看容器日志                             │
│                       │ 排查生产问题                             │
└───────────────────────┴──────────────────────────────────────────┘

## 六、典型工作流

首次开发:  dev-setup → 编辑 .env.custom.dev → dev-start
日常开发:  dev-start ... dev-down
验收测试:  test-start
生产发版:  db-backup ENV=prod → prod-build → prod-push → SSH 服务器 → prod-deploy
同步上游:  sync-upstream → git checkout development && git rebase main → test-start
